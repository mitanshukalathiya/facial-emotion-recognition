Overview:
This project detects human emotions such as happy, sad, angry, surprise, neutral, etc., from live webcam feed using Deep Learning and OpenCV.
A CNN model is trained on the FER2013 dataset and later used for real-time predictions.


How to Run:
1. Clone repo  
2. Install requirements: `pip install -r requirements.txt`  
3. Run real-time demo: `python src/realtime_emotion.py`
